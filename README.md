## What I'm working on

My main project is [**Practice**](https://github.com/Ankush-Manhas840/Practice): every problem I solve, committed as I go, with the solution checked against a brute-force reference and the lessons written up in [notes](https://github.com/Ankush-Manhas840/Practice/tree/main/notes).

| Topic | What's inside |
|---|---|
| **Arrays and Hashing** | sorting algorithms, prefix sums, Kadane, next permutation, frequency maps |
| **Binary Search** | lower/upper bound, rotated arrays, binary search on the answer, 2D matrices |
| **Two Pointers and Sliding Window** | 3Sum / 4Sum, in-place tricks, window limits |
| **Recursion and Math** | recursion basics, number theory, Pascal's triangle |
| **Matrix and Intervals** | spiral, rotation, merge intervals |

I also keep a list of the edge cases that broke my own solutions, because that is where most of the learning happened: [edge-cases-to-revisit](https://github.com/Ankush-Manhas840/Practice/blob/main/notes/edge-cases-to-revisit.md).
